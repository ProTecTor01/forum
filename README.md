# Forum

Веб‑форум на Go для общения пользователей, категоризации постов и взаимодействия через лайки/дизлайки. Использует SQLite для хранения данных и безопасную аутентификацию.

## Описание

Форум позволяет пользователям:
- Регистрироваться и входить в систему
- Создавать посты и комментарии
- Организовывать посты по категориям
- Оценивать посты и комментарии (лайки/дизлайки)
- Фильтровать посты по категориям, созданным или понравившимся постам
- Создавать вложенные комментарии (до 9 уровней вложенности)

Важно: при создании поста нужно выбрать хотя бы одну категорию.

## Технологии

* **Backend:** Go (Golang)
* **Веб‑фреймворк:** стандартная библиотека (`net/http`)
* **База данных:** SQLite3
* **Стилизация:** кастомный CSS
* **Развертывание:** Docker (многоэтапная сборка)
* **Аутентификация:** bcrypt для хеширования паролей, сессии в базе данных

## Установка и запуск

### Docker (рекомендуется для Windows)

1) Установите и запустите Docker Desktop.

2) Запустите скрипт:

Windows PowerShell (Git Bash или WSL):
```powershell
cd src
bash runserver.sh 127.0.0.1:8080
```

Linux/macOS:
```bash
cd src
chmod +x runserver.sh
./runserver.sh 127.0.0.1:8080
```

3) Откройте в браузере: `http://127.0.0.1:8080`

### Стандартный способ (требуется компилятор C)

**Важно:** для работы SQLite требуется C‑компилятор (GCC). На Windows его нужно установить отдельно.

Запуск приложения:

Windows (PowerShell):
```powershell
$env:CGO_ENABLED=1; go run cmd/server/main.go
```
или
```powershell
.\run.ps1
```

Windows (CMD):
```cmd
set CGO_ENABLED=1 && go run cmd/server/main.go
```
или
```cmd
run.bat
```

Linux/macOS:
```bash
CGO_ENABLED=1 go run cmd/server/main.go
```

База данных `forum.db` создается автоматически при первом запуске через миграции.

## Использование

### Основные маршруты

* **Регистрация/Вход**:
  - `/register` — создание аккаунта
  - `/login` — вход
  - `/logout` — выход

* **Посты**:
  - `/posts` — список всех постов
  - `/posts/create` — создание поста (требуется авторизация)
  - `/posts/<id>` — просмотр поста

* **Фильтрация**:
  - По категориям: `/posts?category=<id>`
  - Мои посты: фильтр `my posts` (только для авторизованных)
  - Понравившиеся: фильтр `my liked posts` (только для авторизованных)

* **Комментарии**:
  - Добавление комментариев на странице поста
  - Вложенные комментарии до 9 уровней
  - Удаление собственных комментариев

* **Категории**:
  - `/categories` — список категорий
  - `/categories/create` — создание категории (требуется авторизация)

* **Лайки/дизлайки**:
  - Голосование за посты и комментарии
  - Отображение количества лайков/дизлайков для всех пользователей

* **Интеграция с Hacker News**:
  - `/sync/hackernews` — синхронизация топ‑новостей (POST)
  - Автосоздание категорий "Hacker News", "External Link", "Ask HN"
  - Импорт до 30 историй за один запуск
  - Сохранение оригинальных URL и ID

## Безопасность

* Хеширование паролей через `golang.org/x/crypto/bcrypt`
* Cookies с флагами `HttpOnly`, `Secure` (для HTTPS) и `SameSite=Strict`
* Валидация пользовательских данных (email, username, пароль, длина контента)
* Ограничения БД: внешние ключи, каскадные удаления, уникальные индексы

## Зависимости

* `github.com/mattn/go-sqlite3` — драйвер SQLite
* `golang.org/x/crypto/bcrypt` — хеширование паролей
* Стандартные библиотеки Go: `net/http`, `html/template` и др.

## Переменные окружения

* `PORT` — порт сервера (по умолчанию: 8080)
* `DB_PATH` — путь к файлу БД (по умолчанию: `./assets/database/forum.db`)
* `SCHEMA_PATH` — путь к схеме БД (по умолчанию: `./assets/database/schema.sql`)
* `TEMPLATE_DIR` — директория шаблонов (по умолчанию: `./assets/templates/`)
* `STATIC_DIR` — директория статики (по умолчанию: `./assets/static/`)
* `FORCE_HTTPS` — включить Secure cookies (по умолчанию: `false`)

## Важные замечания

* В production рекомендуется HTTPS для безопасности cookies и трафика.
* Миграции БД выполняются автоматически при запуске (`schema.sql`).
